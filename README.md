# Финансы — PWA приложение для учёта доходов и расходов

Современное веб-приложение для отслеживания личных финансов с поддержкой установки на Android.

## Возможности

- 💰 Учёт баланса, доходов и расходов
- 🚀 Быстрое добавление транзакций (2-3 тапа)
- 📊 Аналитика: топ категорий, топ трат, средний расход в день
- 📈 Прогноз расходов до конца месяца
- 🔄 Сравнение с прошлым периодом
- ✏️ Редактирование и удаление транзакций
- 📴 Офлайн-работа
- 🌙 Тёмная тема
- 📱 Оптимизировано для мобильных устройств

## Установка на Android

### Вариант 1: Через GitHub Pages (рекомендуется)

1. Загрузите проект на GitHub
2. Включите GitHub Pages в настройках репозитория
3. Откройте ссылку на своём Android-устройстве
4. В Chrome нажмите меню (три точки) → "Добавить на главный экран"
5. Приложение установится как обычное Android-приложение

### Вариант 2: Локальный сервер

1. Установите любой локальный HTTP-сервер:
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js
   npx http-server
   
   # PHP
   php -S localhost:8000
   ```

2. Найдите локальный IP вашего компьютера:
   ```bash
   # Windows
   ipconfig
   
   # Linux/Mac
   ifconfig
   ```

3. На Android откройте в Chrome: `http://[ваш-IP]:8000`
4. Нажмите меню → "Добавить на главный экран"

## Генерация иконок

Откройте файл `generate-icons.html` в браузере — он автоматически создаст и скачает PNG-иконки нужных размеров (192×192 и 512×512).

Поместите скачанные иконки в корневую папку проекта.

## Структура проекта

```
├── index.html          # Главная страница
├── styles.css          # Стили
├── app.js              # Логика приложения
├── manifest.json       # PWA манифест
├── service-worker.js   # Офлайн-функциональность
├── icon.svg            # Векторная иконка
├── icon-192.png        # Иконка 192×192
├── icon-512.png        # Иконка 512×512
└── generate-icons.html # Генератор PNG иконок
```

## Использование

1. Введите сумму
2. Выберите тип (расход/доход)
3. Выберите категорию
4. Нажмите "Добавить"

Для редактирования или удаления транзакции — нажмите на неё в списке истории.
